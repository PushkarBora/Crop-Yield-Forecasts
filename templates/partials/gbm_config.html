Grid Search Configuration

Define parameter ranges for exhaustive search using TimeSeriesSplit cross-validation.

💡 Number of past time steps used as input features. Example: 2 to 5 by 1 → tests [2, 3, 4, 5]
💡 Number of boosting stages. Example: 50 to 300 by 50 → tests [50, 100, 150, 200, 250, 300]
💡 Maximum depth of each tree. Example: 2 to 6 by 1 → tests [2, 3, 4, 5, 6]
⚙️ Shrinks contribution of each tree. Example: 0.01 to 0.2 by 0.05 → tests [0.01, 0.06, 0.11, 0.16]
💡 Fraction of samples used per stage. Example: 0.6 to 1.0 by 0.2 → tests [0.6, 0.8, 1.0]
💡 Unlike XGBoost's colsample, GBM uses max_features per split. sqrt and log2 add regularization.
⚠️ Estimated Combinations: Calculating... 📊 Calculation: lags × n_estimators × max_depth × learning_rate × subsample × max_features

💡 Note: GBM uses sklearn's GradientBoostingRegressor — no extra install needed. Key difference from XGBoost: uses max_features (per-split feature sampling) instead of colsample_bytree. A feature importance chart is generated after training.
