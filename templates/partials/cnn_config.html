Grid Search Configuration

Define parameter ranges for exhaustive search. The system will test all combinations to find the optimal configuration.

💡 Sequence length (window size). Example: 2 to 5 by 1 → tests [2, 3, 4, 5]
💡 Base Conv1d filter count — doubles each layer. Example: 8 to 32 by 8 → tests [8, 16, 24, 32]
💡 Conv1d kernel width. Keep odd-numbered for symmetric padding. Example: 3 to 7 by 2 → tests [3, 5, 7]
💡 Depth of the convolutional tower. Example: 1 to 3 by 1 → tests [1, 2, 3]
💡 Applied after each conv block and in the FC head (also used for MC sampling). Example: 0.0 to 0.3 by 0.1
⚙️ Adam optimizer step size
📊 L2 regularization strength
🎯 Loss function robustness parameter
⏱️ Epochs to wait before early stopping
🔄 Maximum training epochs
⚠️ Estimated Combinations: Calculating... 💡 Tip: Fewer combinations = faster training. Adjust ranges to balance speed vs thoroughness.
