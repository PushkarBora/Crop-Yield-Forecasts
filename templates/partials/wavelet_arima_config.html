Grid Search Configuration

The series is split into detail components D1…DJ and a trend AJ (they add back exactly to the original series). An ARIMA model is fitted to every component and the forecasts are added together. The best wavelet filter and level are picked automatically.

Multivariate: each exogenous variable is decomposed the same way and used in the matching component model. Typical training time: a few seconds.
